## 启动方式改造 + Windows 批处理坑（重要）
- GUI 脱离控制台：改用 pythonw.exe -m gtv.boot。pythonw 是 Windows GUI 子系统程序，cmd 调用它不会等待、立即返回，且进程独立，关黑窗不影响它（用户原问题：关控制台窗口 GUI 就消失）
- 新增 gtv/boot.py 引导层：把 stdout/stderr 重定向到 logs/gtv.log，异常用 MessageBoxW 弹原生提示框 —— 解决 pythonw 无控制台导致"启动失败静默消失"的排错难题
- 新增 GTV.vbs：Shell.Run 隐藏窗口方式启动，双击后完全无黑窗
- 批处理两个硬坑：① 必须是纯 ASCII + CRLF，UTF-8 中文会被 cmd 按 GBK 解析成乱码并拆行；② echo 文本中不能含括号，在 if(...) 块内会被当语法符号，报"此时不应有"...；改用 goto 标签式写法最稳
- 依赖安装检查改为先探测 %VENV%\Lib\site-packages\PySide6\__init__.py 目录，避免必须执行 python
- 沙箱环境限制：从 bat 内部派生子进程会"拒绝访问"，且 start / wscript 被安全策略拦截 —— 这类失败属环境限制，真实资源管理器双击不受影响；验证 GUI 存活须用 Start-Process 直接调用 pythonw
